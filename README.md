# 📲 Proyectos Móviles

## ICM - App de Gestión Móvil - 27 mar 2024
**ICM** es una aplicación móvil desarrollada como parte de una colección de proyectos enfocados en soluciones prácticas y funcionales para dispositivos móviles. Esta app representa el primer proyecto del repositorio de aplicaciones móviles.
